# Daily Log: 2026-05-20

## Sessions


### Session (13:37) - Fix post-login redirect to Indie Kit demo page

**Context:** A friend testing the deployed app saw the Indie Kit demo `/app` page (raw `useUser()` JSON dump) instead of the Muneem Ji dashboard after login.

**Key Exchanges:**
- User initially thought it was an error; it was actually the Indie Kit demo dashboard at `src/app/(in-app)/app/page.tsx`.
- Root cause: `src/components/auth/auth-form.tsx` defaulted `callbackUrl` to `/app` in 4 places (lines 44, 72, 90, 114).
- User normally hits `/dashboard` directly, masking the bug; first-time sign-in via form lands on `/app`.

**Decisions Made:**
- Replaced `src/app/(in-app)/app/page.tsx` with a server-side role-based redirect: signed-out → `/sign-in`, business owners → `/owner/dashboard`, CA users → `/dashboard`.
- Changed all 4 `callbackUrl` fallbacks in `auth-form.tsx` from `/app` to `/dashboard`.
- Left billing routes under `(in-app)/app/...` untouched (still Indie Kit-owned).

**Lessons Learned:**
- Indie Kit's `(in-app)/app/` route group ships a demo dashboard that leaks through if auth `callbackUrl` defaults aren't overridden — check these on any Indie Kit fork.
- Bugs invisible to the developer (who has muscle-memory navigation) can surface for fresh users following default flows; test sign-in cold in incognito.
