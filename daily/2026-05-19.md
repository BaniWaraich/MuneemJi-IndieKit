# Daily Log: 2026-05-19

## Sessions


### Session (12:07) - Per-page PDF chunking + currency inheritance fix

**Context:** PDF parser worked for HDFC (30kb) but failed on a 537kb Bank of Ireland statement; debugged through chunking, schema, and currency-mismatch issues.

**Key Exchanges:**
- "Request was aborted" on BoI PDF traced to 180s OpenAI SDK timeout on single-call gpt-4o extraction.
- Per-page chunking implemented in `src/lib/statement-parser/pdf-llm-parser.ts` (concurrency 4, 2 attempts/page, gpt-4o-mini).
- Hit cascading schema failures: row 0 debit/credit strictness, then `balance: null` rejections, then row 0 itself having null balance.
- Final bug: `src/app/api/v1/clients/[id]/statements/route.ts:114` hardcoded `currency: "INR"` ignoring client org currency.

**Decisions Made:**
- Drop per-page debit/credit validation; only merged row 0 needs LLM-provided direction (balance-delta override repairs the rest).
- Allow `balance: number | null`; LLM emits null on blank cells (no guessing/carrying). Floating anchor: find first row with printed balance, back-fill earlier rows from next row's movement, forward-fill later rows.
- Reconcile printed balances against computed ones (warn + trust printed).
- Statement currency inherits from client org on upload — existing INR-tagged records require fresh upload.
- Sandbox can't run on Vercel (long-running Flask, non-root UID, tmpfs, caps) — host separately on Fly/Cloud Run with shared-secret header auth; egress lockdown since compose's `internal: true` net is lost in cloud.

**Lessons Learned:**
- European bank PDFs commonly leave intra-day balance cells blank — schema must tolerate null balance and reconstruct from movement.
- Narration-wrap across page boundaries is a tolerable V1 risk since bank PDFs reset table headers per page.
- Per-page mini calls are net cheaper than single gpt-4o call (~20x cheaper model offsets N calls).
- Currency mismatches between extracted and declared must hard-fail to prevent journal-entry confusion — fix the source (inherit from client), don't loosen the check.
